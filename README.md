# FOSS4G NA 2026 · Mergin Maps

Talk and workshop by Vitor Vieira (Lutra Consulting) for FOSS4G North America 2026, Sacramento.

| | File |
|---|---|
| Talk — *Mergin Maps: field data that stays consistent and reliable* | [`mergin-deck/index.html`](mergin-deck/index.html) |
| Workshop — *From QGIS to the Field and Back* | [`mergin-deck/workshop.html`](mergin-deck/workshop.html) |

Both are self-contained HTML decks. Everything they need (images, demo video, QR codes, the Inter font) is in `mergin-deck/assets/`, so they run **fully offline**.

## Presenting

1. Open `mergin-deck/index.html` (talk) or `mergin-deck/workshop.html` (workshop) in Chrome.
2. Press **F** for fullscreen.
3. **→ / Space / clicker** next, **←** back, **N** speaker notes, **Home / End** first / last slide.
4. Talk slide 8 (demo): the first "next" plays the video, the second moves on.

Keep the `assets/` folder next to the HTML files — the decks don't work without it.

## Not in the repo

The raw screen recordings (`*.mp4` in the root, ~100 MB each) are over GitHub's file limit and stay local. The talk uses a compressed copy at `mergin-deck/assets/demo.mp4`.
